# 📈 當沖多策略與動態風控模擬系統 (Day Trading Simulation System)

一個基於 Java Swing 與物件導向設計的即時台股/期貨當沖交易模擬與回測系統。本應用程式整合了四大主流當沖策略、自動化部位規模計算（Position Sizing）、動態風險報酬比（RR Ratio）停利停損規劃，以及嚴格的風控熔斷機制（Circuit Breaker）。

---

## 🛠 系統架構 (System Architecture)

本專案採用經典的 **Model-Controller-View (MVC)** 架構設計，將核心計算、交易邏輯與圖形介面完全解耦：

1. **`DTSimulation.java` (Model + Controller 核心引擎)**
   * **KBar 資料管理**：接收並維護 5 分鐘 K 線的即時時間戳與 OHLCV（開、高、低、收、量）資料。
   * **四大當沖策略引擎**：支援開盤區間突破 (ORB)、均線均值回歸、VWAP 價量突破及 V 轉反彈策略。
   * **RiskEngine 風控引擎**：管理單日最大虧損上限、觸發熔斷機制、尾盤強制平倉（13:20）及即時停利停損檢查。
   * **TradingEngine 交易執行**：依據本金與單筆風險比例動態計算進場口數/股數。

2. **`DTSimulationUI.java` (View 圖形使用者介面)**
   * 採用 Java Swing 構建的現代化視窗介面。
   * 提供直覺的參數配置面板（本金、風控、風報比、策略選單）。
   * 即時 K 線數據手動輸入與自動時間遞增。
   * 即時監控日誌、損益動態變色顯示、完整使用說明彈窗與列印支援。

## 🚀 核心功能亮點 (Key Features)

### 1. 多策略支援 (Multi-Strategy Support)
* **開盤區間突破 (ORB)**：透過前 3 根 5 分鐘 K 線（共 15 分鐘）建立當日開盤高低價區間，突破上緣做多、跌破下緣做空。
* **均線均值回歸 (Mean Reversion)**：當價格過度偏離模擬均線時，進行逆勢超買做空或超賣做多。
* **VWAP 價量均線突破 (VWAP Breakout/Cross)**：動態計算成交量加權平均價，當價格帶量貫穿 VWAP 時順勢進場。
* **V 轉反彈 (V-Shape Reversal)**：比對前後兩根 K 線的價格型態（如長黑後出現強勢包覆收高）捕捉反轉機會。

### 2. 科學化風控與資金管理 (Risk Management & Position Sizing)
* **動態部位計算**：
  $$\text{Shares} = \frac{\text{Capital} \times \text{RiskRatio}}{\text{RiskPerShare}}$$
  系統自動根據本金與單筆風險比例，計算每次交易所應配置的最佳股數/口數。
* **風報比 (RR Ratio) 設定**：支援 $0.5 \sim 20.0$ 的自由調整，自動依據風險距離推算停利目標價。
* **風控熔斷機制**：當日累計虧損達到設定上限（如 $-\$10,000$）時，自動鎖定交易禁止再開新倉。
* **收盤強制平倉**：內建台股當沖機制，若持倉至每日 13:20 將自動觸發尾盤強制平倉。

## 💻 執行與安裝說明 (Getting Started)

### 系統需求
* **Java Development Kit (JDK)**：建議使用 JDK 8 或以上版本。
* **IDE 建議**：Eclipse, IntelliJ IDEA, 或 NetBeans。

### 執行步驟
1. 將專案中的 `DTSimulation.java` 與 `DTSimulationUI.java` 放在同一個專屬 package（例如 `com`）底下。
2. 透過您的 Java 開關或 IDE 編譯整個專案。
3. 執行主程式 `DTSimulationUI.java` 中的 `main` 方法啟動圖形介面：
   ```bash
   java com.DTSimulationUI
   ```

## 📖 操作流程指南 (User Guide)

1. **參數設定**：
   * 輸入模擬標的代號（例如台積電股票代號 `2330`）。
   * 設定當沖總本金與當日容許最大虧損金額。
   * 透過微調器（JSpinner）設定理想的 **風報比 (RR)** 與 **單筆風險比例**。
   * 選擇您欲測試的 **當沖策略**。
2. **初始化引擎**：
   * 點擊 **「初始化策略引擎」** 按鈕鎖定參數並啟動核心模組。
3. **輸入 5 分鐘 K 線進行回測模擬**：
   * 依序輸入 09:05 的開、高、低、收與成交量，點擊 **「送出 K 線數據」**。
   * 系統將自動遞增時間（每筆 +5 分鐘），並即時在右側日誌視窗顯示進場、風控或平倉訊息。
4. **日常維護**：
   * 盤中可隨時點擊 **「重置當日資料」** 清除累積損益與持倉狀態重新開始。
   * 支援 **「列印日誌」** 與 **「清除日誌」** 功能。
